Data source: connecting… Read-only with one exception — the AC heating ON/OFF setpoints (validated server-side). It still cannot flip any switch directly. That write is an MQTT publish to the Cerbo broker, which a browser will only open from an http page on the farm LAN — this dashboard's own LAN address. On this public https link it is blocked as mixed content, which is deliberate: mobile data can watch the farm, it cannot touch the heating.
Honesty: all numbers are raw dispatcher signals shown with their thresholds. When a feed is stale or a field is missing, you'll see a badge — never a guessed value. History is built from real samples — the farm relay keeps a rolling 24 h, and on the farm network the page also accrues its own. The Node-RED archive endpoints (/api/bsf/*) aren't wired, so there's no deeper backfill than that.
